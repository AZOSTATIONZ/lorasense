    Help & Documentation

    Getting Started
    1. Power on — Connect the ESP32 gateway to USB or a 5V supply. The blue LED blinks during boot.
    2. Connect to Wi-Fi — On your phone or laptop, join the LoRaSense Wi-Fi network. Open 192.168.4.1 in your browser.
    3. Run the wizard — First-time setup asks for your environment name, type, and walks you through sensor and equipment configuration.
    4. Monitor — The dashboard shows live sensor readings, connection health, and equipment status.
    Tip: Bookmark 192.168.4.1 or add it to your home screen for quick access.
    Dashboard

    The dashboard is your main view. It shows:

    • Hero cards — Large sensor readings with trend arrows, sparklines, and range badges (green = in range, red = outside ideal).
    • Status bar — Connection state, node uptime, signal strength, and last update time.
    • Health strip — Visual signal quality, packet loss, and round-trip time.
    • Quick controls — Tap the control bar to toggle equipment on/off directly.
    • Environment tips — Expand "Tips for your environment" for guidance specific to your setup.
    Tap a hero card to see detailed sensor information, reading history, and calibration data.
    Settings

    Open Settings with the gear icon in the top-right corner. Here you can:

    • Environment — Change name and type. Switching types changes the theme, terminology, and automation presets.
    • Relay module — Select your relay channel count (1, 2, 4, or 8). The pin map shows which Arduino Mega pins connect to each relay.
    • Zones — Organise your space into rooms, fields, bays, or areas depending on your environment type.
    • Equipment — Add devices and assign them to relay outputs and zones.
    • Automation rules — Create sensor-triggered rules (e.g. "fan on above 28 °C"). Use the suggested presets for quick setup.
    • Appearance — Choose a visual theme (Friendly, Industrial, Technical) or leave it on Auto.
    • Dark mode — Toggle between light, dark, or system default using the moon/sun icon.
    • Data export — Download sensor history as a CSV file.
    • Backup — Save or restore your full configuration as a JSON file.
    Hardware Studio

    Hardware Studio is the advanced configuration panel for technicians. Access it from Settings.

    • Controller — View the connected Arduino Mega's status and firmware version.
    • Relays — See relay pin assignments and test individual outputs.
    • Pin map — View all Mega pins and their current assignments.
    • Sensors — Commission new sensors, set calibration offsets, and manage driver versions.
    Note: Hardware Studio requires Technician-level access. User-level accounts see the dashboard and controls only.

    Automation Rules

    Automation rules trigger equipment based on sensor readings. Each rule has:

    • Sensor — Which reading to watch (temperature, humidity, or analog).
    • Condition — "Above" or "Below" the threshold.
    • Threshold — The trigger value (e.g. 28.0 °C).
    • Hysteresis — Dead band to prevent rapid on/off cycling (e.g. 1.0 °C means the rule turns off at 27.0 °C if it turned on at 28.0 °C).
    • Equipment — Which relay output to control.

    Rules run on the ESP32 gateway. If the node goes offline, a fail-safe turns all relays off after 60 seconds.

    Troubleshooting
    Cannot connect to LoRaSense Wi-Fi
    Make sure the ESP32 is powered on and the blue LED has stopped blinking. If the network does not appear, press the reset button on the ESP32.
    Dashboard shows "Node offline"
    Check that the Arduino Mega is powered and the LoRa antenna is connected. The node sends a heartbeat every 30 seconds — wait up to a minute.
    Sensor readings show "Awaiting data"
    The node has not sent telemetry yet. Verify the DHT sensor is wired to the correct pin (default: pin 7) and wait for the first reading cycle (10 seconds).
    Relay does not switch
    Check that the relay module is wired to the correct Mega pin (22–29) and that the equipment is assigned to the right output in Settings. Test the relay directly from Hardware Studio.
    All relays turned off unexpectedly
    The fail-safe activates after 60 seconds without hearing from the gateway. This protects against communication loss. Check LoRa connectivity.
    Dark mode not working
    Tap the sun/moon icon in the header to cycle between light, dark, and system default. If your phone is set to dark mode, "system" will follow it automatically.
